# C12 이슈 상세 화면 — 작업 기록

> 2026-11-09 · `feat/issue-detail-screen` · API 기록은 [c-page12-implementation.md](c-page12-implementation.md)

## 범위

- `/teams/[id]/issues/[issueId]` 화면을 Figma 12(`198:486`)에 맞춰 새로 만들었다. 기존 화면 코드(`IssueDetailView`, CSS, 테스트)는 지우고 `page.tsx`·`loading.tsx`만 남겨 고쳤다.
- 그대로 쓴 것: `_lib/issue-detail-queries.ts`의 12 API 호출, 목업 `p12-issue-detail.ts`, 생성 타입, 백엔드(GitHub 반영·`issue_sync_jobs` 포함), 시트 4개의 저장 로직. `_lib`에는 `/sub-issues` 읽기 옵션(`subIssuesOptions`) 하나만 더했다.
- 새 파일: `e2e/c-issue-detail.spec.ts`, `issue-sheets/sheet-class-names.ts`.
- 엔드포인트·테이블·페이지 수는 그대로다(205 REST, 69 테이블).

## Figma 상태

- `198:486` 하나뿐이다. 같은 페이지에서 12의 하위 프레임(시트·수정 화면)은 찾지 못했다(`13-이슈 상태`는 13, `22-시작일 마감일 바텀 시트`는 22 화면).
- 구성: 헤더(뒤로 가기·"이슈 상세"·`⋮`, 팀 이름·탭 없음), 제목 + `↗`, `#번호 · 레포 · 작성자 작성`, 정보 카드 5줄(상태·라벨·담당자·시작일·마감일), "이슈 본문" 상자, "하위 이슈 N/M 완료" 목록, "채팅방 공유" 버튼.

## 기존 화면에 있었지만 Figma에 없어 만들지 않은 것

1. "이슈 목록" 뒤로가기 글자 링크, 헤더 뒤로 가기로 대신
2. "GitHub에서 열기" 글자 버튼: `↗` 아이콘(화면 낭독기에는 같은 이름)으로 바꿈
3. 작성자 사진과 "N분 전 작성" 시간
4. "이 레포에 쓸 권한이 없어 보기만 할 수 있어요…" 안내: 줄을 누를 때 토스트로만 알림
5. 값 옆의 "변경" 버튼 4개: 줄 전체를 누르는 것으로 바꿈
6. 상태 배지·"닫힌 이슈" 표시, 라벨 색 점, 담당자 사진
7. "마감 지남" 글자와 "일정 없음"·"내용이 없어요."·"담당자 없음"·"라벨 없음" 빈 값 문구
8. "하위 N개 중 M개 완료" 한 줄: Figma의 'N/M 완료' 머리글로 바꿈
9. `⋮` 아이콘은 Figma에 있지만 열리는 화면이 없고 시트는 줄에서 열려 만들지 않았다
10. **"채팅방 공유" 버튼**: Figma에 있지만 준호님 확인으로 제외(만들지 않음)
11. 본문 상자의 눈 아이콘 3종(비활성 인풋 디자인 흔적)

**Policy와 다른 부분(수정 안 함):** "마감 지남" 글자 표시(Policy 7장·POL-I-4)와 04 12장 "권한 없음" 안내 상시 노출이 사라짐, Page TODO 12의 "하위 3개 중 1개 완료" 문구가 'N/M 완료'로 바뀜, "작업 중단"의 "중단" 표시(POL-I-3)는 상태 이름으로만 나옴.

## 검증 (로컬, 2026-11-09)

- frontend `pnpm lint` 오류 0(경고 6개는 이번 변경과 무관), `pnpm typecheck` 통과.
- Vitest `issues/[issueId]`와 `issue-sheets` 15개 통과(`--maxWorkers=2`). 새 `IssueDetailView.test.tsx` 7개: Figma 12 요소·하위 이슈·안전한 마크다운·axe, 줄 4개가 각 시트를 URL로 열기, 상태 저장, 쓰기 권한 없음 토스트.
- e2e `c-issue-detail.spec.ts` 7개 통과(시연 이슈 1022 포함)(`pnpm dev:mock`, 서버 하나, 끝난 뒤 종료): 머리글·`↗`·정보 줄·"채팅방 공유" 없음, 줄 → 상태 시트 저장, 읽기 전용 팀, 360·375·600px 가로 스크롤 없음 + axe(`color-contrast` 제외).
- 화면 확인: 375px 캡처를 Figma 12와 비교해 제목·메타·정보 카드(35px 간격)·본문 상자를 맞췄다. 목업 이슈에 하위 이슈가 없어 하위 이슈 영역은 Vitest로 확인했다.
- 로컬이 느려(부하) e2e 제한 시간을 90초로 늘렸다.
- `pnpm test` 전체, `pnpm build`, 백엔드는 돌리지 않았다. 푸시하지 않았다.
