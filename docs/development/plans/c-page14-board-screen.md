# C14 상태 보드 화면 — 작업 기록

> 2026-11-08 · `feat/issue-board-screen` · API 기록은 [c-page14-implementation.md](c-page14-implementation.md)

## 범위

- `/teams/[id]/board` 화면을 Figma 14(`200:1028`, 정렬 메뉴 `368:3414`, 필터 메뉴 `368:3562`, 카드 상태 메뉴 `368:3741`)에 맞춰 새로 만들었다. 기존 화면 코드(`BoardView`, `hook`, CSS, 테스트)는 지우고 `page.tsx`·`loading.tsx`만 남겨 고쳤다.
- 그대로 쓴 것: `board/_lib/board-queries.ts`, `board-view/api.ts`, 12번 상태 API(`saveStatus`), 목업 `p14-board.ts`, 생성 타입, 백엔드. 11의 `TeamFrame`·`TeamNav`·`IssueFilterButton`·`IssueFilterSheet`(`showStatus={false}`)는 고치지 않고 썼다.
- 새 파일: `board-view`(화면·칸), `board-card`(카드·끌기 미리보기), `board-menu`(드롭다운 3종 공용), `board/_lib/board-sort.ts`, `e2e/c-issue-board.spec.ts`.
- 엔드포인트·테이블·페이지 수는 그대로다(205 REST, 69 테이블).

## 확정한 결정 (사용자 결정, 2026-11-08)

| 항목 | 결정 |
| --- | --- |
| 정렬 | "최신순 / 오래 된 순"은 **화면에서 이슈 ID순**으로 정렬한다(카드에 생성일이 없고 API에 정렬이 없음). 기본 최신순 = ID 큰 순, URL `?sort=oldest`. **API 계약의 "마감 급한 순"과 다르다**(c-page14-implementation.md) |
| 필터 메뉴 | 하나를 고르면 **그 상태 칸만** 보인다. 같은 것을 다시 고르면 해제된다. URL은 11 필터의 `status`를 그대로 쓰고, 보드 API 요청에는 넣지 않는다(기존 `boardOptions`) |
| 상태 문구 | Policy POL-I-3로 통일: 작업 전·작업 중·작업 중단·작업 완료(+기타). Figma의 '진행 전/진행 중/완료/중단'은 쓰지 않았다. 메뉴 순서는 Figma대로(작업 중 → 작업 전 → 작업 완료 → 작업 중단) |
| 남긴 동작 | 나머지 칸(작업 중단·작업 완료)과 카드가 있을 때만 '기타' 칸, 카드 끌어서 옮기기(마우스 6px, 터치 길게 누르기, 쓰기 권한 있을 때만) |
| 칸 머리 '+' | Figma 14(`214:100`, `232:75`)대로 칸마다 넣었다. 쓰기 권한이 있으면 `/teams/[id]/issues/new`(13)로 가고, 없으면 숨긴다(07·11 '+'와 같은 방식). 상태는 미리 정하지 않는다 (사용자 결정, 2026-11-08 추가) |
| 만들지 않은 것 | GitHub 라벨 색(Figma처럼 연한 파랑·보라를 번갈아 씀) |
| 메뉴 방식 | 바텀 시트가 아니라 Figma대로 버튼 아래 드롭다운(메뉴 버튼 패턴, `menuitemradio`, 방향키·Esc). 시트·모달이 아니라서 `useOverlay`와 URL `overlay`를 쓰지 않았다. 칸 가로 스크롤에 잘리지 않게 `position: fixed`로 띄우고 스크롤하면 닫는다 |
| 카드 상태 메뉴 | 고르는 즉시 12번 상태 API로 저장한다(먼저 옮기고, 실패하면 되돌리고 토스트, POL-I-4). 쓰기 권한이 없으면 열리지 않고 04 12장 "권한 없음" 문구를 토스트로 보여 준다 |
| 칸 색 | 칸 윗줄·상태 점은 Policy대로 보드 매핑 색(`statusColor`)을 쓴다. Figma의 '작업 전' 검정(`#121212`)과 다르다 |
| 마감 지남 | 07·11처럼 날짜만 빨강, 화면 낭독기에는 "마감 지남"으로 읽힌다 |
| 키보드 | 끌기는 마우스·터치만. 키보드·화면 낭독기는 카드 상태 메뉴로 옮긴다(끌기 대신 쓸 버튼, frontend AGENTS.md) |
| 대비 낮은 색 | Figma 값 유지: `#98a3b4`(개수·레포·날짜·선택 안 된 메뉴 행) 2.28–2.55:1. 디자인 가이드 §1-3에 기록. e2e axe는 `color-contrast`만 예외 |
| 그림자 | 칸 `--shadow-board-column`, 메뉴 `--shadow-board-menu`를 디자인 가이드 4장 예외로 기록 |

새 토큰은 `styles/tokens/color.css`·`layout.css`·`typography.css`와 디자인 가이드 1-1·1-3·3-4·4장에 추가했다. 기존 토큰 값은 바꾸지 않았다.

## 기존 화면에 있었지만 Figma에 없어 만들지 않은 것

1. 도구 막대 안내 "카드의 손잡이를 끌거나(모바일은 길게 누르기) "상태 바꾸기"로 옮겨요."
2. 쓰기 권한이 없을 때 안내 "이 레포에 쓸 권한이 없어 보기만 할 수 있어요…": 이제 상태 메뉴를 누를 때 토스트로만 알린다
3. 끌기 손잡이(⋮⋮)와 키보드 끌기(방향키로 칸 이동): 카드 전체 끌기와 상태 메뉴로 바꿨다
4. **"상태 바꾸기" 버튼과 12의 상태 시트**(설명 + "저장"): 카드 상태 드롭다운(즉시 저장)으로 바꿨다. **Policy POL-I-4·Page TODO 14의 "상태 바꾸기" 메뉴 문구와 다르다**
5. **카드의 "중단" 표시**: 상태 칸에 '작업 중단'만 보인다. **Policy POL-I-3("Blocked … shows 중단 on the card")과 다르다**
6. **"일정이 GitHub에 반영되지 않았어요" 카드 문구**: 11처럼 화면 낭독기용 텍스트로만 남겼다. **Policy 7장 Sync("the issue card shows …")와 다르다**
7. "마감 {날짜} · 마감 지남" 문구: 날짜만(빨강) 보인다
8. 담당자 아바타(최대 3명 + "+N"): "{이름}, {이름} 담당" 글자로 바꿨다
9. 라벨의 GitHub 색 점
10. 칸 머리의 상태 배지, 빈 칸의 "이슈 없음", 기타 칸 설명 "보드의 상태 칸이 네 가지에 대응되지 않은 이슈예요."
11. 옮긴 뒤 성공 토스트: 화면 낭독기 알림(`role="status"`)으로만 남겼다

Policy·Page TODO는 수정하지 않았다.

## 검증 (로컬, 2026-11-08)

- frontend `pnpm lint` 오류 0(경고 6개는 이번 변경과 무관한 파일), `pnpm typecheck` 통과.
- Vitest `app/(developer)` 139개 통과(`--maxWorkers=2`). 새 `BoardView.test.tsx` 8개: Figma 요소, 기타·NONE, 정렬(URL `sort`), 필터 메뉴, Esc·포커스 복귀, 상태 메뉴 저장, 실패 시 되돌림, 권한 없음.
- e2e `c-issue-board.spec.ts` 8개 통과(`pnpm dev:mock`, 서버·테스트 하나씩): 머리글·탭·칸·'+' → 13, 정렬·필터 URL, 상태 메뉴로 옮기고 되돌리기, 마우스로 끌어 옮기고 되돌리기, 읽기 전용 팀, 360·375·600px 가로 스크롤 없음 + axe.
  - 첫 실행에서 모바일 화면이 1145px로 넓어지는 문제를 찾았다. 카드의 sr-only 글자(`position: absolute`)가 위치 지정 없는 스크롤 칸에 잘리지 않아서였고, `.columns`에 `position: relative`를 줘서 고쳤다.
- 화면 확인: 375px 캡처를 Figma 4개 상태와 비교했다. 뒤로 아이콘 '<'는 11 결정대로 공용을 그대로 쓴다.
- `pnpm test` 전체, `pnpm build`, 백엔드는 돌리지 않았다(백엔드 변경 없음). 푸시하지 않았다.
