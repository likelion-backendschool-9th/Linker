# 개인정보 처리방침

## 제1조 (수집하는 개인정보 항목 및 목적)

- **가입 (필수)**
  - **수집 항목:** GitHub 사용자 ID, 핸들, 이름, 프로필 사진, 이메일, GitHub 액세스 토큰
  - **이용 목적:** 로그인, 회원 식별, 계정 안내, GitHub 연동
  - **처리 근거:** 동의

- **프로필 (선택)**
  - **수집 항목:** 표시 이름, 자기소개, 블로그 주소, 기술 스택, 팀 구하기 여부, 구직 상태, 관심 직군
  - **이용 목적:** 프로필 표시, 팀 찾기, 추천, 채용 제안 수신, 선택한 관심 직군에 맞는 채용 공고 표시
  - **처리 근거:** 동의

- **GitHub 활동**
  - **수집 항목:** 공개 기여 기록(잔디), 저장소 정보, 조직 구성원 정보, 이슈·PR·담당자 정보
  - **이용 목적:** 기여 기록 및 게시물 카드 표시, 팀 협업 기능 제공
  - **처리 근거:** 계약 이행

- **서비스 이용 중 생성 정보**
  - **수집 항목:** 게시물 및 사진, 댓글, 좋아요·팔로우·차단 관계, 모집글 및 지원 정보, 팀 채팅과 1:1 채팅 메시지 및 이미지
  - **이용 목적:** 소셜, 팀, 채팅 기능 제공
  - **처리 근거:** 계약 이행

- **신고 및 제재 정보**
  - **수집 항목:** 신고 내용, 신고된 메시지와 그 전후 메시지 사본(잠정적으로 각 10개), 제재 이력
  - **이용 목적:** 신고 처리, 악용 방지
  - **처리 근거:** 정당한 이익 또는 법령

- **자동 수집 정보**
  - **수집 항목:** 접속 시각, IP 주소, 기기 정보(OS·앱 버전), 푸시 토큰, 서비스 이용 기록, 쿠키
  - **이용 목적:** 보안, 악용 방지, 알림, 서비스 개선 통계
  - **처리 근거:** 계약 이행 또는 법령

- **알림 이메일**
  - **수집 항목:** GitHub에 공개 이메일이 없을 때 별도로 입력한 이메일
  - **이용 목적:** 계정 및 서비스 안내
  - **처리 근거:** 동의

- **마케팅 (선택)**
  - **수집 항목:** 이메일, 푸시 토큰
  - **이용 목적:** 이벤트 및 신규 기능 안내
  - **처리 근거:** 별도 동의

- **AI 요약 (Flex 팀)**
  - **수집 항목:** 요청한 범위의 팀 채팅 메시지, 요약 결과
  - **이용 목적:** AI 요약 생성
  - **처리 근거:** 계약 이행

- **기업회원 (채용 담당자)**
  - **수집 항목:** 이름, 회사 이메일, 단방향 해시된 비밀번호, 회사명, 직책, 선택 입력한 회사 웹사이트
  - **이용 목적:** 기업회원 가입, 회사 이메일 확인, 채용 제안 메시지
  - **처리 근거:** 동의

- **프로필 열람 기록**
  - **수집 항목:** 기업회원이 개발자 프로필을 열람한 날짜 및 기업회원 식별 정보 (하루 1회)
  - **이용 목적:** Pro 회원에게 주간 열람 **횟수** 안내 (열람자는 공개하지 않음)
  - **처리 근거:** 계약 이행

- **채용 공고 (Scout 구독)**
  - **수집 항목:** 공고 제목, 직군, 외부 공고 URL, 마감일, 공고별 일일 조회·클릭 집계 (개인을 식별하지 않음), 공고 닫기·숨기기 기록
  - **이용 목적:** 피드 채용 공고 표시, 종료된 공고 숨김 유지, 부적절한 공고 신고 처리
  - **처리 근거:** 계약 이행

- **기업회원 확인**
  - **수집 항목:** 이메일 인증 코드 및 비밀번호 재설정 링크 (해시 저장)
  - **이용 목적:** 이메일 소유 확인, 비밀번호 재설정
  - **처리 근거:** 계약 이행


- 업로드한 사진은 저장 전에 EXIF 위치 정보를 제거합니다.
- 비공개 저장소와 비공개 조직의 활동은 회원의 동의 없이 프로필이나 피드에 표시하지 않습니다.
- 팀 기능을 이용하면 같은 GitHub 조직의 다른 사람(Linker 미가입자 포함)의 GitHub 핸들, 프로필 사진 및 이슈 활동이 팀 화면에 표시될 수 있습니다. GitHub 조직 소유자가 Linker 앱 설치 때 허용한 범위에서만 가져오며, GitHub에서 삭제되면 Linker에서도 삭제합니다.
- 주민등록번호, 민감정보, 정밀 위치정보는 수집하지 않습니다.

## 제2조 (개인정보 보유 및 이용 기간)

개인정보는 회원 탈퇴 또는 처리 목적 달성 시 지체 없이 파기합니다. 다만 아래 정보는 표시된 기간 동안 보관합니다. 표의 기간은 잠정 기준입니다.

- **회원 정보**
  - **보유 기간:** 탈퇴 신청 후 30일
  - **보유 이유:** 탈퇴 철회 (기간 내 로그인하면 복구)

- **이메일 인증 코드·재설정 링크**
  - **보유 기간:** 사용 또는 만료 후 1일 (코드 유효기간 10분, 링크 30분)
  - **보유 이유:** 인증 시도 확인

- **GitHub 액세스 토큰**
  - **보유 기간:** 탈퇴 또는 연동 해제 즉시 삭제
  - **보유 이유:** 연동 종료

- **게시물·댓글·사진**
  - **보유 기간:** 삭제 즉시, 백업에서는 30일 이내 삭제
  - **보유 이유:** 백업 주기

- **팀 채팅 메시지**
  - **보유 기간:** 팀이 존재하는 동안. 탈퇴 후 작성자를 “탈퇴한 사용자”로 표시
  - **보유 이유:** 팀 작업 기록 보존

- **1:1 채팅**
  - **보유 기간:** 양쪽 이용자가 모두 나가면 삭제
  - **보유 이유:** 상대방의 열람 권리

- **채팅 이미지 원본**
  - **보유 기간:** 무료 팀 90일, Flex 팀은 팀이 존재하는 동안 (Flex 종료 후 무료 팀 기준 30일 적용), 1:1 채팅 1년. 이후 미리보기만 보관
  - **보유 이유:** 저장 공간 관리

- **프로필 열람 기록**
  - **보유 기간:** 90일
  - **보유 이유:** 주간 열람 횟수 집계

- **신고 자료**
  - **보유 기간:** 처리 완료 후 1년
  - **보유 이유:** 이의 제기 및 분쟁 대응

- **제재 이력**
  - **보유 기간:** 제재 후 1년. 영구 정지는 GitHub ID만 [N년] 보관
  - **보유 이유:** 재가입을 통한 제재 회피 방지

- **접속 기록 (로그인 시각, IP)**
  - **보유 기간:** 3개월
  - **보유 이유:** 통신비밀보호법 준수

- **서비스 이용 기록**
  - **보유 기간:** 90일
  - **보유 이유:** 보안 및 악용 대응

- **푸시 토큰**
  - **보유 기간:** 로그아웃 또는 탈퇴 즉시 삭제
  - **보유 이유:** 알림 종료

- **AI 요약 결과**
  - **보유 기간:** 7일
  - **보유 이유:** 요청자의 재확인

- **마케팅 동의 기록**
  - **보유 기간:** 동의 철회 시까지
  - **보유 이유:** 정보통신망법 준수


유료 구독 결제 시 카드번호 등 결제수단 정보는 저장하지 않고, 결제 내역(상품, 금액, 결제 시각, 거래 ID)만 처리합니다. 전자상거래법에 따라 계약 및 청약철회 기록과 대금 결제·공급 기록은 5년, 소비자 불만 및 분쟁 처리 기록은 3년간 보관합니다.

## 제3조 (개인정보의 제3자 제공)

회사는 다음의 경우를 제외하고 이용자의 개인정보를 제3자에게 제공하지 않습니다.

1. 이용자가 공개하거나 전송하기로 선택한 정보가 다른 이용자에게 보이는 경우. 예를 들어 프로필(이름, 프로필 사진, 자기소개, 기술 스택, 기여 기록, 완료 기록, 게시물), 게시물 및 모집글은 로그아웃한 방문자에게도 공개될 수 있고, Google·Naver 등 검색엔진 검색 결과에 노출될 수 있습니다. 기업회원 프로필은 검색엔진에 공개하지 않습니다. 회원 또는 게시물이 삭제되면 Linker에서는 즉시 보이지 않지만, 검색엔진에 남은 사본은 검색엔진이 다시 수집한 후 삭제됩니다. 모집글에 지원하면 작성자에게 프로필이 표시됩니다. 구직 상태를 “제안 받기”로 설정하면 해당 정보는 기업회원(채용 담당자)에게만 표시됩니다.
2. 채용 제안 과정에서 회원의 이메일이나 연락처를 기업회원에게 제공하지 않습니다. 1:1 채팅에서 회원이 직접 공유한 연락처는 회원이 직접 전송한 정보입니다.
3. 구체적인 법률 조항에 근거하거나 수사기관이 법에서 정한 절차에 따라 요청한 경우.

## 제4조 (개인정보 처리 위탁 및 국외 이전)

회사는 서비스 제공을 위해 아래 업체에 개인정보 처리를 위탁합니다. 일부 업체는 해외에 있어 개인정보가 국외로 이전됩니다. 국외 이전은 서비스 계약 이행에 필요하며 개인정보 보호법 제28조의8 제1항 제3호에 따라 이 방침에 공개합니다. 대괄호로 표시한 업체명·국가·기간은 출시 전에 실제 이용 업체 기준으로 확정해야 합니다.

- **[백엔드 호스팅 업체] ([국가])**
  - **위탁 업무:** 서버, 데이터베이스, 파일 저장
  - **이전 항목:** 제1조에 기재한 개인정보 전체
  - **이전 시기 및 방법:** 이용 중 지속적으로 네트워크 전송
  - **보유 기간:** 위탁 계약 종료 시까지

- **Vercel Inc. (미국)**
  - **위탁 업무:** 웹 화면 제공, 접속 기록
  - **이전 항목:** IP, 기기 정보, 접속 기록
  - **이전 시기 및 방법:** 접속 시
  - **보유 기간:** 위탁 계약 종료 시까지

- **GitHub, Inc. (미국)**
  - **위탁 업무:** 로그인, GitHub 연동
  - **이전 항목:** GitHub 계정 정보, 이용자가 작성한 이슈·담당자 정보
  - **이전 시기 및 방법:** 기능 이용 시
  - **보유 기간:** GitHub 정책에 따름

- **650 Industries, Inc. (미국, Expo Push) / Google LLC (미국, FCM)**
  - **위탁 업무:** 푸시 알림 전송
  - **이전 항목:** 푸시 토큰, 알림 내용
  - **이전 시기 및 방법:** 알림 전송 시
  - **보유 기간:** 위탁 계약 종료 시까지

- **[이메일 업체] ([국가])**
  - **위탁 업무:** 계정 안내 및 인증 이메일 발송
  - **이전 항목:** 이메일
  - **이전 시기 및 방법:** 이메일 발송 시
  - **보유 기간:** 위탁 계약 종료 시까지

- **[분석 업체: PostHog / Google Analytics] ([국가])**
  - **위탁 업무:** 이용 통계
  - **이전 항목:** 기기 정보, 이용 기록 (가명 식별자)
  - **이전 시기 및 방법:** 이용 중 지속적으로 전송
  - **보유 기간:** [기간]

- **[오류 추적 업체] ([국가])**
  - **위탁 업무:** 오류 분석
  - **이전 항목:** 기기 정보, 오류 로그
  - **이전 시기 및 방법:** 오류 발생 시
  - **보유 기간:** [기간]

- **[AI 업체] ([국가]) (회사 서버에서 Ollama로 처리하면 이 행 삭제)**
  - **위탁 업무:** 팀 채팅 AI 요약
  - **이전 항목:** 요약 요청 범위의 채팅 메시지
  - **이전 시기 및 방법:** 요약 요청 시
  - **보유 기간:** 처리 후 저장하지 않으며 학습에 사용하지 않음


유료 구독 결제 처리는 토스페이먼츠 주식회사(대한민국)에 위탁합니다. 회사는 카드번호를 받지 않습니다.

국외 이전에 동의하지 않는 이용자는 계정을 탈퇴하거나 개인정보 보호책임자에게 문의할 수 있습니다. 다만 위 업체들은 주요 기능 제공에 필요하므로 이전을 거부하면 해당 기능을 이용할 수 없습니다.

## 제5조 (개인정보 파기 절차 및 방법)

1. 보유 기간이 끝나거나 처리 목적을 달성한 개인정보는 5일 이내 파기합니다.
2. 전자 파일은 복구할 수 없도록 삭제하고, 백업 데이터는 백업 주기(잠정 30일) 내에 삭제합니다.
3. 법령에 따라 보관해야 하는 정보는 다른 개인정보와 분리하여 보관하고 해당 목적으로만 이용합니다.

## 제6조 (이용자의 권리와 행사 방법)

1. 이용자는 언제든지 개인정보 열람, 정정·삭제, 처리 정지 또는 동의 철회를 요청할 수 있습니다.
2. 프로필과 게시물은 앱에서 직접 수정·삭제할 수 있습니다. 그 밖의 요청은 [개인정보 보호책임자 이메일]로 접수하며 10일 이내 처리합니다.
3. 내 정보 내려받기 기능(프로필, 게시물)은 2단계에서 설정에 제공할 예정입니다. 제공 전까지는 이메일로 요청할 수 있습니다.
4. 대리인을 통해 권리를 행사할 때는 위임장이 필요합니다.
5. 다른 이용자의 권리를 침해할 수 있는 경우(예: 상대방에게 전달된 1:1 메시지, 팀 채팅 기록)에는 법령에 따라 일부 요청이 제한될 수 있습니다.

## 제7조 (자동 수집 장치 및 행태정보)

1. 웹과 앱은 로그인 유지를 위해 쿠키와 기기 저장소를 사용합니다. 브라우저 설정에서 쿠키를 차단할 수 있으나 로그인이 작동하지 않을 수 있습니다.
2. 회사는 서비스 개선을 위해 분석 도구로 화면 이동 및 버튼 사용 기록을 수집합니다. 이 기록을 광고에 사용하지 않습니다.
3. 피드 추천은 팔로우 관계, 좋아요·댓글 수, 기술 스택 태그를 기준으로 하며 각 게시물에 추천 이유를 표시합니다.
4. 피드 채용 공고는 회원이 프로필 수정에서 선택한 관심 직군만을 기준으로 표시하며, 화면 이동이나 클릭 같은 행태정보를 사용하지 않습니다. 관심 직군을 선택하지 않으면 채용 공고를 표시하지 않으며, 기업회원에게 특정 회원이 공고를 보았는지 알리지 않습니다.

## 제8조 (개인정보 안전성 확보 조치)

- 관리적 조치: 내부 관리 계획 수립, 운영자 권한 최소화 (운영자·리드 운영자), 정기 교육
- 기술적 조치: GitHub 토큰 및 비밀번호 암호화, 전 구간 HTTPS, 백오피스 2단계 인증 및 30분 자동 로그아웃, 백오피스 이메일 마스킹, 접속 기록 보관
- 운영자는 신고되지 않은 채팅을 볼 수 없으며, 운영자의 모든 조치는 담당자·시각·사유와 함께 기록합니다.

## 제9조 (만 14세 미만 아동의 개인정보)

회사는 만 14세 미만 아동의 가입을 받지 않습니다. 가입 후 만 14세 미만으로 확인되면 계정과 개인정보를 삭제합니다.
