# 이용약관

## 제1조 (목적)
이 약관은 Linker가 제공하는 서비스의 이용 조건과 절차를 정합니다.

## 제2조 (회원)
회원은 개발자 회원과 채용 담당자 회원으로 나뉩니다.

- 개발자 회원은 GitHub 계정으로 가입해요.
- 채용 담당자 회원은 회사 메일로 가입해요.

## 제3조 (금지 행위)
스팸, 허위 모집, 사칭 등은 [커뮤니티 정책](/legal/community)에 따라 제재돼요.
