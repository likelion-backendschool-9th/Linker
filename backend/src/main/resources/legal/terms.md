# 이용 약관

## 제1조 (목적)
이 약관은 \[회사명\](이하 “회사”)이 제공하는 Linker 서비스(이하 “서비스”)의 이용 조건과 절차, 회사와 회원 간의 권리·의무 및 책임사항을 규정합니다.

## 제2조 (정의)
1. “서비스”란 회사가 웹·앱으로 제공하는 개발자 소셜, 팀 워크스페이스, 팀 찾기, 채팅, 채용 제안 등 일체의 기능을 말합니다.
2. “회원”이란 이 약관에 동의하고 GitHub 계정으로 가입한 자를 말합니다.
3. “사업 회원”이란 별도 부가약관에 동의하고 회사 메일로 가입한 채용 담당자를 말합니다.
4. “콘텐츠”란 회원이 서비스에 게시한 프로젝트 게시물, 댓글, 모집글, 채팅 메시지 등을 말합니다.

## 제3조 (약관의 게시와 개정)
회사는 이 약관을 서비스 내 설정 및 웹사이트에 게시합니다. 약관을 개정하는 경우 시행일 7일 전(회원에게 불리한 변경은 30일 전)부터 공지하며, 회원이 시행일까지 이의를 제기하지 않으면 동의한 것으로 봅니다.

## 제4조 (회원가입)
만 14세 이상인 자는 GitHub 로그인과 약관·개인정보 처리방침 동의를 통해 가입할 수 있습니다. 타인의 계정 사용, 허위 정보 기재, 영구 정지된 GitHub 계정으로는 가입이 제한될 수 있습니다.

## 제5조 (계정 관리)
회원의 핸들은 GitHub 로그인으로 따르며, GitHub에서 변경되면 서비스에도 반영됩니다. 회원은 계정과 기기의 보안을 관리할 책임이 있습니다.
