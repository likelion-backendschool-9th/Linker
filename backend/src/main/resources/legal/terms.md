# 이용 약관

## 제1조 (목적)
이 약관은 [회사명] (이하 "회사")이 제공하는 Linker 서비스(이하 "서비스")를 이용하는 조건과 절차, 회사와 회원의 권리·의무·책임을 정합니다.

## 제2조 (용어의 정의)
1. "서비스"란 회사가 모바일 앱과 웹으로 제공하는 개발자 소셜 네트워크, 팀 워크스페이스, 팀 찾기, 채팅, 채용 제안 등 일체의 기능을 말합니다.
2. "회원"이란 이 약관에 동의하고 GitHub 계정으로 가입한 개인을 말합니다.
3. "기업회원"이란 별도 추가약관에 동의하고 회사 이메일로 가입한 채용 담당자를 말합니다.
4. "GitHub 연동"이란 회원이 허락한 범위에서 회사의 GitHub App이 GitHub(GitHub, Inc.)의 데이터를 읽고 쓰는 것을 말합니다.
5. "게시물"이란 회원이 서비스에 올린 작업물 글, 사진, 댓글, 모집 글, 지원 메시지, 채팅 메시지 등 모든 콘텐츠를 말합니다.
6. "팀"이란 GitHub 조직 1개와 연결된 서비스 내 협업 공간을 말하며, 오너·관리자·멤버 역할을 둡니다.
7. "모집 글"이란 팀 찾기에서 함께할 사람을 찾는 글을 말합니다.

## 제3조 (약관의 게시와 변경)
1. 회사는 이 약관을 서비스 설정 화면과 웹사이트에 게시합니다.
2. 회사는 관련 법령을 어기지 않는 범위에서 약관을 바꿀 수 있습니다. 바꿀 때는 시행일 7일 전부터, 회원에게 불리한 변경은 30일 전부터 앱 공지와 알림(또는 이메일)으로 변경 내용과 시행일을 알립니다.
3. 회원이 시행일까지 거부 의사를 밝히지 않으면 변경에 동의한 것으로 봅니다. 단, 회사는 이 효과를 공지에 분명히 적어야 합니다. 동의하지 않는 회원은 탈퇴할 수 있습니다.

## 제4조 (약관 외 준칙)
이 약관에 없는 사항은 회사가 서비스 안에 게시하는 운영정책, 개인정보 처리방침, 관련 법령과 상관례를 따릅니다.

## 제5조 (가입)
1. 만 14세 이상인 누구나 GitHub 계정으로 로그인하고 이 약관과 개인정보 수집·이용에 동의해 가입할 수 있습니다. 만 14세 미만은 가입할 수 없습니다.
2. 회사는 다음 경우 가입을 거절하거나 가입 후 이용 계약을 해지할 수 있습니다.
   1. 영구 정지된 GitHub 계정으로 다시 가입하는 경우
   2. 타인의 GitHub 계정을 쓰거나 허위 정보를 넣은 경우
   3. 만 14세 미만임이 확인된 경우
3. GitHub에 공개 이메일이 없으면 알림·계정 안내용 이메일을 따로 입력하고 인증해야 합니다.

## 제6조 (계정 관리)
1. 회원의 아이디는 GitHub 아이디를 따르며, GitHub에서 바꾸면 서비스에도 따라 바뀝니다.
2. GitHub 계정과 기기의 보안은 회원이 관리합니다. 타인이 내 계정을 쓰는 것을 알게 되면 곧바로 GitHub 비밀번호를 바꾸고 회사에 알려야 합니다.
3. 회사는 회원의 고의·과실 없이 생긴 계정 도용 피해에 대해서는 책임을 지지 않습니다. 단, 회사의 고의·과실이 있으면 그렇지 않습니다.

## 제7조 (탈퇴)
1. 회원은 언제든 설정에서 탈퇴할 수 있습니다.
2. 탈퇴하면 계정은 즉시 비활성화되고 30일 뒤 삭제됩니다(가안). 그 사이에 다시 로그인하면 탈퇴가 취소됩니다.
3. 탈퇴하면 작업물 글·댓글은 삭제됩니다. 팀 채팅에 남긴 메시지는 팀의 업무 기록이므로 삭제되지 않고 작성자가 "탈퇴한 사용자"로 표시됩니다. 이 점에 동의하지 않으면 탈퇴 전에 직접 삭제할 수 있습니다.
4. 팀 오너는 오너를 넘기거나 팀을 삭제한 뒤 탈퇴할 수 있습니다.
5. 탈퇴해도 GitHub에 쓴 데이터(이슈, 코멘트, 조직 멤버십 등)는 GitHub에 남습니다. GitHub에서 Linker 앱 권한을 직접 취소해야 연동이 완전히 끝납니다.

## 제8조 (연동 범위)
1. 회사는 회원과 GitHub 조직 오너가 GitHub에서 허락한 권한 안에서만 GitHub 데이터를 읽고 씁니다.
2. 이슈 작성·담당자 배정·상태 변경처럼 GitHub에 쓰는 동작은 회원 본인의 명의와 권한으로 실행되며, 그 결과는 GitHub에 기록됩니다.
3. 이슈·담당자·날짜·조직 멤버처럼 GitHub가 원본인 데이터는 GitHub 기록을 기준으로 하며, 서비스에 보이는 값은 그 사본입니다.
4. 비공개 레포와 비공개 조직 활동은 회원의 동의 없이 프로필·피드에 노출하지 않습니다.

## 제9조 (GitHub 이용 조건)
1. 회원은 GitHub의 이용약관과 정책을 함께 지켜야 합니다.
2. GitHub의 장애, 정책 변경, 호출 한도(예: 신규 조직의 하루 초대 수 제한)로 연동 기능이 멈추거나 늦어질 수 있습니다. 이때 회사는 사본으로 화면을 보여주고 그 사실을 표시합니다.
3. GitHub에서 앱 권한을 취소하거나 조직에서 앱을 제거하면 관련 기능을 쓸 수 없습니다.

## 제10조 (제공 기능)
회사는 다음 기능을 제공합니다. 세부 기능은 서비스 화면과 공지에 따릅니다.
1. 프로필, 커밋 기여 기록(잔디), 완주 기록
2. 작업물 게시, 피드, 좋아요·댓글·팔로우
3. 팀, GitHub 조직 초대, 이슈 작성·배정·일정 관리
4. 팀 채팅, 1:1 채팅
5. 팀 찾기(모집 글, 지원)
6. 구직 상태 표시와 기업회원의 채용 제안 메시지(1:1 채팅 요청)
7. AI 채팅 요약(2단계)

## 제11조 (서비스의 변경·중단)
1. 회사는 운영·기술상 필요에 따라 기능을 바꾸거나 종료할 수 있습니다. 주요 기능을 종료할 때는 30일 전에 알립니다.
2. 점검, 설비 장애, 통신 두절, 외부 서비스(GitHub 등) 장애가 있으면 서비스가 일시 중단될 수 있습니다. 미리 알 수 있는 점검은 사전에 알립니다.
3. 서비스 전체를 종료할 때는 60일 전에 알리고, 회원이 자신의 게시물을 내려받을 수 있는 방법을 안내합니다.

## 제12조 (유료 서비스)
1. 기본 기능은 무료이며, 회사는 유료 구독(Pro: 개인, Team: 팀 오너가 멤버 수만큼 결제)을 제공합니다. 플랜별 혜택과 가격은 구독 화면에 표시하며 모두 부가세 포함 금액입니다.
2. 결제는 웹과 앱에서 같은 결제 화면으로 전자지급결제대행사(토스페이먼츠)를 통해 카드로 합니다. 앱스토어 인앱결제는 제공하지 않습니다.
3. 무료 체험은 계정당 1회, 7일(가안)입니다. 체험이 끝나 유료로 바뀌기 전에 결제 예정일과 금액을 미리 알립니다.
4. 구독은 해지하지 않으면 같은 주기로 자동 갱신됩니다. 가격을 올릴 때는 30일 전에 알리고 동의를 받으며, 동의하지 않으면 다음 갱신일에 구독이 끝납니다.
5. 회원은 언제든 해지할 수 있고, 해지해도 이미 결제한 기간이 끝날 때까지 혜택을 씁니다. 남은 기간에 대한 일할 환불은 하지 않습니다.
6. 결제일로부터 7일 안에 유료 혜택을 한 번도 쓰지 않았다면 전액 환불을 요청할 수 있습니다(청약철회). 혜택을 쓰기 시작하면 전자상거래법 제17조 제2항에 따라 청약철회가 제한되며, 회사는 이를 결제 화면에 미리 알립니다.
7. 결제가 실패하면 7일(가안) 동안 혜택을 유지하며 결제 수단 변경을 안내하고, 그 뒤에도 결제되지 않으면 무료로 전환합니다.
8. 만 19세 미만 회원이 법정대리인의 동의 없이 결제하면 본인 또는 법정대리인이 취소할 수 있습니다.
9. 회사의 잘못으로 유료 기능을 연속 [24시간] 이상 쓰지 못하면 그 기간만큼 구독 기간을 늘려 드립니다.
10. 기업회원 기능은 무료입니다. 채용 담당자 유료 플랜은 출시할 때 별도로 정해 알립니다.

## 제13조 (팀과 팀 찾기)
1. 팀은 GitHub 조직에 Linker 앱을 설치해야 만들 수 있으며, 오너·관리자·멤버의 권한은 운영정책에 따릅니다.
2. 팀 찾기에 지원하면 회원의 프로필(기술 스택, 잔디, 작업물, 완주 기록)이 모집 글 작성자에게 보입니다.
3. 회사는 회원들이 팀을 이루는 공간을 제공할 뿐, 모집 내용의 사실 여부나 팀원 사이의 약속(역할, 수익 배분, 지식재산권 귀속 등)에 당사자로 참여하지 않습니다. 팀 활동의 결과물 권리는 팀원끼리 직접 정하기를 권합니다.
4. 완주 기록은 운영정책에 적힌 기준으로 자동 계산되며, 개인의 역량을 보증하는 지표가 아닙니다.

## 제14조 (채팅)
1. 회사는 채팅 내용을 서비스 제공을 위해 저장하지만, 운영자는 신고된 메시지와 그 앞뒤 10개(가안) 외에는 대화를 볼 수 없습니다.
2. 팀 채팅에는 연결 레포의 PR 생성·리뷰 요청·머지·닫힘 알림이 자동으로 게시됩니다.
3. 맞팔로우가 아니거나 같은 팀이 아닌 회원에게 보내는 첫 1:1 메시지는 상대가 수락해야 대화가 열립니다.
4. 회원이 구직 상태를 "구직 중" 또는 "제안만 받기"로 정하면 기업회원이 채용 제안 메시지를 보낼 수 있습니다. 회원은 구직 상태를 언제든 끌 수 있고, 끄면 새 채용 제안을 받지 않습니다. 회사는 채용 제안의 내용과 채용 결과를 보증하지 않습니다.

## 제15조 (게시물의 권리)
1. 게시물의 저작권은 작성한 회원에게 있습니다. 레포의 코드와 README의 권리는 그 레포의 저작권자와 라이선스를 따릅니다.
2. 회원은 회사가 서비스를 운영·표시·개선·홍보하는 데 필요한 범위에서 게시물을 무상으로 저장·복제·수정(크기 조절, 위치 정보 삭제 등)·전송·게시할 수 있는 비독점적 권한을 허락합니다. 서비스 밖 홍보(보도자료, SNS 등)에 특정 회원의 게시물을 쓸 때는 미리 동의를 받습니다.
3. 이 허락은 게시물을 삭제하거나 탈퇴하면 끝납니다. 단, 다른 회원이 공유하거나 팀 채팅에 남은 부분, 백업에서 지워지기까지 걸리는 30일(가안)은 예외입니다.
4. 회사는 회원의 게시물을 인공지능 모델 학습에 쓰지 않습니다. 학습에 쓰려면 약관을 바꾸고 별도 동의를 받습니다.

## 제16조 (게시물의 책임과 관리)
1. 게시물에 대한 책임은 작성한 회원에게 있습니다. 타인의 레포를 자신의 작업물처럼 올리거나 타인의 사진·코드를 무단으로 올려서는 안 됩니다.
2. 회사는 게시물이 법령이나 운영정책을 어기면 운영정책에 따라 숨기거나 삭제할 수 있습니다.
3. 타인의 권리를 침해한다는 요청이 있으면 정보통신망법 제44조의2에 따라 임시조치를 할 수 있습니다(운영정책의 권리침해 신고와 임시조치 참고).

## 제17조 (회사의 의무)
1. 회사는 안정적으로 서비스를 제공하기 위해 노력하며, 개인정보를 개인정보 처리방침에 따라 보호합니다.
2. 회사는 회원의 의견·불만을 [고객센터 이메일]로 받고, 접수 후 영업일 3일(가안) 안에 답하거나 처리 일정을 알립니다.

## 제18조 (회원의 의무)
회원은 다음 행위를 해서는 안 됩니다. 구체적인 기준은 운영정책에 있습니다.
1. 타인의 계정·개인정보를 도용하거나 동의 없이 노출하는 행위
2. 스팸·광고, 욕설·비방, 성적 콘텐츠, 표절·도용, 허위 모집
3. 서비스나 GitHub API를 비정상적으로 호출하거나, 자동화 도구로 대량 수집·가입·팔로우하는 행위
4. 서비스에서 얻은 다른 회원의 정보를 서비스 밖에서 영리적으로 쓰는 행위
5. 보안 취약점을 악용하거나 서비스 운영을 방해하는 행위. 취약점을 발견하면 [보안 신고 이메일]로 알려 주세요.
6. 그 밖에 법령을 어기는 행위

## 제19조 (이용 제한)
1. 회사는 회원이 제18조를 어기면 경고, 7일 정지, 30일 정지, 영구 정지 순서로 이용을 제한할 수 있습니다. 불법·성적 콘텐츠와 스팸 계정은 바로 영구 정지할 수 있습니다.
2. 회사는 제재 사유와 기간을 알림으로 알리며, 회원은 알림에서 1회 이의를 제기할 수 있습니다. 이의는 처음 처리한 사람이 아닌 다른 운영자가 검토합니다.
3. 영구 정지되면 이용 계약이 해지되며, 같은 GitHub 계정으로 다시 가입할 수 없습니다.

## 제20조 (책임의 제한)
1. 회사는 천재지변, 전쟁, 기간통신사업자·GitHub 등 외부 서비스의 장애처럼 회사가 막을 수 없는 사유로 생긴 손해에 책임을 지지 않습니다.
2. 회사는 회원끼리, 또는 회원과 기업회원 사이에 서비스를 통해 생긴 거래·협업·채용 분쟁에 개입할 의무가 없으며, 그로 인한 손해에 책임을 지지 않습니다.
3. AI 요약·추천·완주 기록처럼 자동으로 만든 결과는 참고용이며 정확성을 보장하지 않습니다.
4. 이 조의 내용은 회사의 고의 또는 중대한 과실로 생긴 손해에는 적용하지 않습니다.

## 제21조 (손해배상)
회사 또는 회원이 이 약관을 어겨 상대방에게 손해를 입히면 그 손해를 배상합니다.

## 제22조 (준거법과 관할)
이 약관은 대한민국 법을 따르며, 분쟁이 생기면 민사소송법에 따른 관할 법원에서 해결합니다.
